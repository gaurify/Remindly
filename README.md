# Remindly

A lightweight desktop reminder application designed to help you stay
organized and remember what matters, with a clean, distraction-free
interface.

## Features

- Simple, focused reminder interface
- Custom reminder messages
- Scheduled reminders with specific times
- Clean, minimal desktop experience

## Preview

A live preview of the app's interface is built into the landing page
— open `index.html` in a browser to see it. Product screenshots will
be added here once the desktop builds are released.

## Tech Stack

- HTML5 & CSS
- [Tailwind CSS](https://tailwindcss.com/) (via CDN)
- No build step, framework, or dependencies
