Everything you need to know about installing and using Remindly.

Getting started

Windows and macOS builds are currently in development. Here's what the process will look like once downloads are live.

1

Download Remindly

Go to the Remindly home page and download the version that matches your operating system.

2

Install the application

Open the downloaded installer and follow the installation instructions for your operating system.

3

Create your first reminder

Enter your reminder message, select the time and activate the reminder.

Frequently asked questions

What is Remindly?

Remindly is a lightweight desktop reminder app focused on a simple, distraction-free way to remember important tasks.

Is Remindly free?

Pricing hasn't been finalized yet. Windows and macOS builds are currently in development, and pricing details will be shared once they're released.

Which operating systems are supported?

Remindly is being built for Windows and macOS. Downloads for both platforms will appear on the home page once builds are released.

Can I set a custom reminder message?

Yes. You can enter the message that you want Remindly to display when your reminder is triggered.

What happens if my operating system shows a security warning?

Operating systems may display security warnings for applications that are not distributed through their official stores. Only allow an application to run if you obtained it from a source you trust.

Where can I find updates?

Check the Remindly GitHub repository for future releases and project updates.
